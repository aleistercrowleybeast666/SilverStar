## Behavior and reviewed scope

Old projects and the default remain `legacy`; explicit `eskf_window_sram` remains supported. Choose `auto` in generated configuration/GUI or `make MEMORY_LAYOUT=auto`; use a fresh isolated generated project for validation. Auto uses a separate build directory. Generated Python reuses the existing resource-audit parser, audits actual object sections, enumerates at most 32 real linker candidates and performs one final selected ARM link. Physical fit precedes rational minimax utilization, spread, fewer moves from legacy CCM and stable name ordering. Actual placement, alignment, startup zero intervals, object/source/linker/ELF hashes are recorded in `memory_layout/decision.json` and printed in build output.

The only movable groups are private CPU-only BSS: ESKF backend `s_work` (3140 B), `s_history` (16992 B), `s_eskf_window` (184 B); estimator task `s_replay_storage` (10368 B); navigation-health `s_groups` (320 B). Their audited owners and called first-party helpers use CPU accesses, not peripheral DMA publication; provenance binding rejects edited/preserved owners/helpers. Exact section, symbol, size, uniqueness and 8-byte alignment checks reject unreviewed groups or initialized CONTENTS sections. The original initialization and ordinary `.data` copy remain untouched; group BSS placement is within original SRAM or CCM NOLOAD startup zero intervals. No heap, live relocation, math, log content/rate or stack-size changes.

Dual-region auto is limited to the reviewed F407 independent physical banks. Unknown banks and aliases fail closed. A no-CCM ordinary-SRAM path is tested with synthetic linker fixtures; no F412/F413 product port or board test is claimed. DMA buffers remain outside the whitelist. The artifact gate checks every linked UART1–6 RX DMA, TX and priority TX symbol, rejects duplicate names and verifies full ranges in DMA-accessible SRAM. Existing mandatory UART1–3 and other DMA checks remain.

Late link/audit/report exceptions remove the current ELF and success decision and preserve candidate scripts, logs and traceback. Four fault tests first reproduce the previous internal candidate-body leak, then prove the transactional wrapper removes both artifacts for wrong bank, invalid zero bounds, usage exception and report-write exception.

Margins remain red below 10%, green above 20%, yellow otherwise; low margins warn. Physical overflow/error blocks. The historical 100 KiB full-rate logging budget remains a hard legacy/manual regression boundary; explicit auto prints it and warns when CPU-only relocation exceeds it. Physical capacities, DMA, stack reservation and initialization remain blocking. Budget spare and physical spare are not proven stack margin.
