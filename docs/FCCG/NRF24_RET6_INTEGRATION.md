## Remaining acceptance boundaries

No real RET6/NRF board was available or touched. RF exchange, CE wiring, SPI
timing, I2C pull-ups, SD durability/power loss, hardware stack high-water and MCU
WCET/navigation/flight qualification are unmeasured. CRC16/volatile session IDs
do not establish cross-reboot anti-replay or exclude identity-reuse collisions.

qualification; it is not silently changed to ONE_FACE or automatic calibration.

logic is unchanged. No GNSS is present in this RET6 minimum: barometer-assisted
vertical state does not bound horizontal inertial drift. The compact RFT6
NEO-M9N+E28 reference remains the independent full four-module option.
