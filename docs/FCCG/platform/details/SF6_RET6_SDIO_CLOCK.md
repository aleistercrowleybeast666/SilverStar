# SF6 RET6 SDIO clock correction

2026-10-05, isolated `codex/sf6-compact-ret6`, base `53e34ebf04d34e8b0abdb5f8d5dcc1489ffea564`.
This is a compile/Host checkpoint, not hardware or flight acceptance. No hardware was accessed.

The F1 Flight plugin owns this change. F407, F1 Ground, ordinary SCG configuration and the logger queues/profile are unchanged. The actual CubeMX RET6 project uses HSI/2, PLL x16, HCLK 64 MHz. Its old SDIO initialization divider 118 generated 533.333 kHz; transfer divider 0 generated 32 MHz. These exceed the 400 kHz initialization and 25 MHz default-speed limits respectively. Changing only `hsd.Init.ClockDiv` does not change the vendor initialization divider.

`HAL_SD_InitCard` now resolves initialization from `HAL_RCC_GetHCLKFreq()` before writing CLKCR, and rejects a transfer divider/bypass configuration that exceeds default speed. The helper uses nominal HCLK plus a 10% upper allowance, a 350 kHz initialization target, and the F103 formula HCLK/(divider+2). At 64 MHz it selects 200: nominal 316.832 kHz, guarded upper 348.515 kHz. At 48/72 MHz the tested dividers are 149/225. Zero, above-72-MHz, overflowing inputs, divider above 255, bypass and overspeed transfer configurations retain ordinary error returns. This margin is a project calculation, not measured oscillator qualification.

ST DS5792 Rev 13, table 25 gives factory HSI up to +2.5% at 3.3 V across -40..105 C. The project allowance exceeds that stated value; operation outside the stated electrical conditions is not qualified by this arithmetic. Source: https://www.st.com/resource/en/datasheet/cd00191185.pdf .

The official CubeMX 6.15 CLI loaded the existing real `.ioc`, executed `set ip parameters SDIO ClockDiv 2`, saved and generated successfully. Both the new `.ioc` and CubeMX `sdio.c` contain divider 2. Fresh SCG import/generated output uses the owning HAL correction. Nominal transfer is 16 MHz, guarded upper 17.6 MHz; no high-speed negotiation is claimed. Normal regeneration still preserves user-owned payloads; validation used the disposable owned project.
