# SilverStar 0.1.2 本地源码分发说明

产品版本取根 `VERSION`。此版准备包含 SCG、GSHC、FLP 的运行源码、资源、SCG builtin 声明式插件、共享机器契约、根启动器与安装说明；不修改程序功能。最终 Git commit、annotated tag、白名单文件原始/分发 SHA256 在包内 `RELEASE_MANIFEST.json` 中，ZIP SHA256 与解压验证记录在包旁 receipt 中。

## 本版纳入内容

- SCG：合并已验收的 MCU catalog 正常路径修复、异步 GUI/native 候选流程及文档；未知配置继续拒绝，普通 native USB 生成继续阻断。
- GSHC：已验收的 AIR epoch/deploy 标记、轨迹显示与对应正常功能修复；ACK 与 READY 保持不同语义。
- FLP：已验收的 GNSS 导出数据依赖、Recorded 窗口、Recomputed 时间映射等正常功能；补充水平/垂直 GNSS 图统计窗口解释，保留阶梯和数据空白。
- 根 README：三应用安装与启动、SCG 配置/生成/构建、独立烧录边界、日志输入与 CLI、支持矩阵、插件/API、许可证及故障排查。

## 包的形成与使用

这是本地源码候选 ZIP，不是 EXE/安装器，也未公开上传。只收 Git 跟踪且在白名单中的文件，不复制工作树、SDK、虚拟环境或历史原始日志。先解压到可写目录，再按根 README 创建 Python 环境。Python 依赖从包源安装，未提供离线依赖仓库。

为移除原机器路径，分发时对少量 JSON 来源路径字段作可移植替换，保留 SDK 包/文件名、commit 与摘要；仓库文件不变。该变化属于分发元数据处理，不证明被引用 SDK 已随包交付。开发过程报告、测试证据与用户数据不随包分发。FLP 历史文档中指向被排除文件的链接会标为完整仓库参考，保留解释文字；当前详尽入口是根 README。

## 已验证与未验证

最终合并版本曾有 25 项针对性 Python 检查通过、三应用真实窗口离线启动/事件循环/退出通过。最终源码 ZIP另做文件摘要、入口、文档链接与离线启动检查，结果以实际 receipt 为准。没有宣称整套测试全通过或全体固件在最终 tag 重建。

F103C8 / C071FBP6 classic CDC 是 EXPERIMENTAL 私有候选，F407 TIM1/Ground 为私有正常路径候选；正式 USB EP0 独立审查没有通过结果，普通入口 BLOCKED。PoT critical-contract review 为 NOT PROVEN；静态软件检查不代表栈、WCET、TF、实际通信或飞行安全验收。本次无 DAPLink、串口、烧录、START 或真实硬件操作。
