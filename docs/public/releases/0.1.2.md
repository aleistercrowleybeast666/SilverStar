# SilverStar 0.1.2 分发说明

版本取根 `VERSION`。本轮准备 Windows 64 位便携候选：`SCG.exe`、`GSHC.exe`、`FLP.exe`、单一共用 `_internal`、文档和许可材料；另保留原源码候选及旧 receipt。用户计划于北京时间 2026-10-12 01:00 发布，这不是已经执行的发布。当前 tag/推送状态须以最终 receipt 和远端读回为准。

## 本版内容与边界

SCG 保留已验收的 catalog、正常生成及 GUI/native 候选流程；未知配置拒绝，普通 native USB 入口保持 BLOCKED。GSHC 保留 AIR epoch/deploy、正常轨迹显示等修复，ACK 不等于 READY。FLP 保留日志与 exact decoder 配对、Recorded/Recomputed 时间轴、GNSS 导出与窗口解释。程序源码和共享契约冻结，本轮只改文档和打包配置。

[Windows 使用说明](../WINDOWS_PACKAGE.md)包含目录结构和 GSHC 既有 D 盘默认数据路径及环境变量设置。完整解压到可写短目录，不单独复制 EXE，也不覆盖合并三套独立 dist。外部 Arm 工具链与 SDK 不随包提供。无安装器、最终固件、视频或发布文章交付。

## 检查与证据

历史合并版本的25项针对性 Python 检查和源码窗口烟测只归属其原记录。本次 Windows 实包重新做冻结运行时的三应用真实 main.py 窗口/事件循环/退出、普通参考工程生成与保留用户源码、合成日志处理、生产 LogOpenCoordinator 精确解码及数据导出；具体成功/失败、命令、版本和 SHA256 以本次 receipt 为准，不把历史结果拼成全仓库通过。

冻结运行时的8项针对性检查与41项文档测试在各自最终批次通过。随后从含中文和空格的实包路径、任意工作目录直接启动三个发布 EXE：SCG 打开合成参考工程，GSHC 未连接地面站并生成明确标记的模拟日志，FLP 打开合成日志及 exact decoder，显示 Recorded 数据。实际 EXE 检查未覆盖所有交互、生成、重算或导出；这些功能的前述冻结 QA 证据分别记录。SCG/GSHC 以退出码0正常关闭；FLP 的未保存提示及关闭结果以旁置证据为准。旧 SCG/FLP 界面截图采用 en_US，仅作为技术证据；发布示例与说明采用简体中文，不为换截图再启动前台窗口。没有纯净 Windows 机器验证。首次路径长度、ICU/NumPy 打包错误和测试辅助函数错误的失败日志均保留。

F103C8/C071FBP6 classic CDC 是 EXPERIMENTAL 私有候选，F407 TIM1/Ground 为私有正常路径候选；正式 USB EP0 独立审查没有通过结果，普通入口 BLOCKED。PoT critical-contract review 为 NOT PROVEN。软件工具检查不代表栈、WCET、实际通信或飞行资格；无串口连接、DAPLink、烧录、CONNECT、START 或真实硬件操作。
