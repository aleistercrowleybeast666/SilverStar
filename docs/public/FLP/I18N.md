# Internationalization

Core, parser, and algorithm layers emit stable codes and units. GUI and export translations live in
the i18n resources. GUI language and export language are independent; export can follow the UI or
select Simplified Chinese/English explicitly. All exported filenames use `_ZH` or `_EN`, and the
same resolved language controls titles, axes, legends, annotations, event labels, and statistics.

`ChannelDisplayMetadata` separates stable internal channel IDs from localized plot titles and
quantity labels. Professional abbreviations and axis symbols (IMU, INS, KF_6, GNSS, ENU, NIS,
E/N/U, X/Y/Z, Xb/Yb/Zb, WXYZ, and q_nb) remain stable. All current SSLOG event codes have ZH/EN
timeline labels; the raw code remains available in the tooltip.

Replay fidelity values, every current warning code, What-if parameter labels, result information,
and Stored Results columns have complete ZH/EN text. Warning codes and parameter IDs remain raw in
tooltips for diagnosis. The visible Chinese provenance for What-if is the user-facing
"hypothetical parameter replay" concept, while the internal `ReplayMode.WHAT_IF` value stays
language-independent.

Export language choices are **Follow UI** (default), **简体中文**, and **English**. Follow UI is
resolved before writing any product, so manifests never contain an unresolved language and every
filename still ends in `_ZH` or `_EN`.
