# 常用导航参数与高级参数（0.1.3 开发版）

SCG 导航配置不再用外层折叠框隐藏所有算法参数。公共重力、算法 basic 参数，以及
GNSS/气压观测噪声、已有观测延迟、NIS 软/硬门开关直接显示。
初始协方差、NIS 阈值、杆臂等其余高级项和 GNSS 完整性项继续折叠，保持各自展开状态。

FLP 复算页直接显示过程模型、观测噪声、SF6 增益和 NIS 开关；高级按钮展开后，
通过原有分类选择其余参数。切换分类不移除常用参数，不丢失尚未复算的编辑值，
重置仍恢复当前模式的实际基线。记录模式只读，离线默认值仍不是飞控实际记录值。
ESKF15 旧 schema 把全部字段归入过程模型；界面按 P0、杆臂、NIS 的既有语义细分，
保留原 schema identity，不把协方差和杆臂误放入常用区。

这是呈现层修改：不改变插件 manifest、参数 schema/默认值、工程格式、算法调用、
已有日志、decoder 包或原始记录。SF6 仍只有当前态固定增益，不新增协方差、历史或延迟模式；
纯 INS 不添加融合、观测门限或延迟选项。

已有延迟毫秒参数继续沿用原语义。0 ms 不能作为关闭回放的代称：KF6 与 ESKF15 的
历史引擎仍存在，可信采样时间优先；KF6 对无可信 epoch 且 delay=0 还保留旧的当前应用时间分支。
“无回放”“延迟回放”“延迟预测”模式尚须单独实现、版本化及差分验证，本次界面不假装支持新模式。

验证：SCG 常用参数可见性、编辑/刷新、参数契约和 NIS 关联用例 166 通过，
历史 `test_generated_defaults_numerically_identical_and_changed_values_consumed` 的
golden 不匹配另有既有证据，本批明确排除 1 项，未修改 golden。
FLP 参数分类切换/保值/重置、纯 INS/SF6/ESKF 分组边界、NIS 与翻译关联用例 148 通过。
这些界面验证不是算法精度、延迟补偿、重捕获或硬件验收。
