# Manual attachments

New project roots include an `Attachments/` folder alongside `Log/` and the
target folders. In SCG, **File > Open Attachments** creates it for an existing
project and opens that directory. Save or open a project first.

Copy supporting documents there manually. SCG does not inspect, import or
execute the contents. A same-named file, symbolic link or junction is rejected;
existing user files are preserved. Attachments do not change generation inputs.
