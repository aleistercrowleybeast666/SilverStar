# 测试证据保留与软件验证范围

测试源码按安全契约保留，不以减少文件数量为目标。应保留协议解析与 READY/ACK、生成与导入边界、不可覆盖用户输入、日志/decoder 配对、存储完整性、并发与 GUI 生命周期、固件正常及故障回归，以及 Host 夹具和生成模板内测试。历史证据可以独立归档，构建对象与可再生缓存可以清理；原始录制数据和输入夹具不属于缓存。

验证证据按每次执行的源码提交或可审计快照归属，保留实际命令、工具版本、配置、完整结果、失败、跳过和产物摘要。归档与去重保持原始字节，不能把不同提交的若干通过结果拼接成未执行的全套通过。存档时不重新运行测试，也不改变既有结论。

Host/GUI 回归、源图检查、Power10 文本检查、真实分析器编译和 ARM 链接各自只证明其记录范围。软件工具通过不证明实机通信、USB 枚举/断开重连、飞行性能、最坏执行时间或完整栈裕量。Power10 检查是项目门禁，关键契约人工审查和未解决的 NOT PROVEN 仍限制验收；既有 BLOCKED/EXPERIMENTAL 状态不因归档而变更。

可公开内容应为去敏的方法、范围、结论与限制，并引用仓库内相对路径和提交。原始外场日志、硬件读回、完整私有命令记录、截图和本机绝对路径留在受控证据存档，不直接纳入公开文档。
本轮仓库测试与夹具按原安全契约保留；发布包不捆绑无关开发 tests，不为减少文件数删除关键回归或原始输入。可再生产物的清理与必要证据的去重归档分别记录，未获批准前不删除唯一本地证据。归档不改变历史验收结论。
