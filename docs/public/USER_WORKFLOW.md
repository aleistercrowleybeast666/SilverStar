# SilverStar 桌面工作流

1. 打开 SCG 的“硬件与通信”。分别选择飞控、地面站板卡或导入对应的 CubeMX 工程，在同一个共享无线窗口核对两端模块和空口设置。地面站到电脑使用 UART，可通过外部 USB-UART 桥连接。
2. 在“任务流程”点击阶段或共享功能编辑属性，核对功能的开始与结束阶段。在“检查与生成”选择就绪目标，生成后运行构建和检查。保存工程、对应的 ELF/map 和生成的 .ssdecoder。工程生成与设备操作分别进行。
3. 在 GSHC 选择地面站 COM 口和匹配的波特率并连接。当前协议为 SS-TM-S。飞前 CAP 握手和设备报告决定可用操作，阶段 ENTER/EXIT 仅用于任务呈现。观察到成功 START、任务事件或飞行数据后，本次飞控 boot 的地面上行关闭。
4. 通过设备维护入口使用飞控维护 UART 校准磁力计。按设备物理身份选择实例、采集、检查拟合结果，再按需应用与保存。检查设备读回和重启加载状态。[磁力计操作](GSHC/MAGNETOMETER_CALIBRATION.md)。
5. “定位找回”显示最后有效 WGS84 坐标、定位年龄与来源。断线或重启后仍能复制该历史点。维护串口的日志导出支持校验和取消。保留原日志与配套解码包。
6. 在 FLP 打开或拖入 .bin 或 .sslog，程序用记录中的 Descriptor 在任务目录、用户配置目录及精确缓存中寻找配套包。若需补救，选择对应的 .ssdecoder，或调整搜索目录后重试。通过时间线、设备与参数详情查看记录，再保存工程和导出结果。

理解惯导、SF6、KF6、ESKF15从[实现说明](algorithms/NAVIGATION_IMPLEMENTATION.md)进入，公式文档注明坐标/符号/假设/源码身份。日志或接收数据推导的轨迹不是位置真值；阶梯、空白和故障诊断不能为了展示插值/抹平。

源码推荐组合见[支持矩阵](SUPPORT_MATRIX.md)，它区分配置起点、历史证据和未验证项。公共文档不附实测用户数据、串口连接脚本或内部审查结果；具体结果以其自身receipt为准。
