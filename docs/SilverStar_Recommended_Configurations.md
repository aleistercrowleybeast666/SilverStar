# SilverStar 推荐组合与验证范围

适用于 0.1.1 发布准备，更新于 2026 年 10 月 7 日。当前日常代码身份为 `fd1954b3652d638e773be21b7553e3ac78c7f060`，尚未创建 tag 或 Release。

初次使用建议从下列组合起步，保留项目、固件、decoder 和记录的对应关系。推荐组合不构成禁选规则：400 Hz IMU 与 JY901B 气压高频仍可选，不新增统一限频，也不把高频配置写成首发已实测可用。

## 推荐组合

| 用途与目标 | 算法及设备起点 | 证据级别与边界 |
| --- | --- | --- |
| 主力路线：F407 | KF6；JY901B、NEO-M9N、E28 | 有旧版本 0027/0028 历史外场记录。最新工程仍待最后一轮板测，不能把旧记录迁移为最新版本整体验收 |
| 轻量探索：F103RFT6 | SF6；MPU6050 200 Hz、M9N 25 Hz、BMP280 标称 20 Hz、E28-2G4M12SX、SDIO TF；无维护串口 | 已有软件、Host 与构建证据，尚无该组合实机结论。参考构建为 64 MHz、soft-float |
| 最简探索：F103RET6 | SF6；MPU6050 200 Hz、BMP280、NRF24、SDIO TF；无 GNSS、无维护串口 | 已有软件与构建证据，F103、NRF24 未实机验证。无 GNSS 时，水平位置会随惯性积分漂移，不能当作长期稳定的位置解 |
| 性能评估：H7 | ESKF15；传感器和接口按实际板件另行核对 | 建议评估组合，尚未上板。所测 F407 配置的 ESKF15 实际运行失败仍保留，不能据此宣布 H7 已可用 |

“推荐”表达配置起点；“已软件验证”仅涵盖所列源码、Host 或构建检查；“历史实机”必须绑定原硬件、固件与条件；“未验证”不能用器件标称能力补成通过。F103 实机验证不作为本次首发前的强制条件，未验证状态继续披露。

## 档位和资源

四档不与 MCU 或无线模块永久绑定。默认 `normal/est` 队列容量为：

| 档位 | normal | est |
| --- | ---: | ---: |
| 完整 | 80 | 48 |
| 标准 | 80 | 48 |
| 轻量 | 56 | 16 |
| 最简 | 24 | 16 |

对应参考工程的构建报告值：

- F103RFT6 轻量：Flash 256748 B；静态 RAM 86872/98304 B，余 11432 B，约 11.629%
- F103RET6 最简：Flash 209472 B；静态 RAM 54208/65536 B，余 11328 B，约 17.285%；soft-float Cortex-M3，64 MHz
- MSP 已计入静态 RAM，不重复扣除；Flash 使用构建报告口径，不混用 section/span 等其他口径
- 资源提示沿用“20% 以上绿色、10% 以下红色、中间黄色”的建议范围，不据此增加生成禁令，也不把颜色作为安全证明
- Logger 已分析调用链为 2736/3072 B，静态余量 336 B；MSP/ISR 的完整证明仍未完成

在上述 200 Hz 推荐配置下，RET 与 RF 的持续日志预算分别为 29992 B/s、41892 B/s，事件和元数据另计。这是配置预算，不是 TF 卡实测带宽或最坏写入保证。

## 频率应怎样理解

设备采样、驱动新帧、惯性传播、融合提交与日志记录是不同频率。

- MPU6050 当前固定 200 Hz，`SMPLRT_DIV=4`、`DLPF=3`；两样本聚合对应 INS 100 Hz
- M9N 25 Hz 是 RF 轻量参考的推荐工作点，不代表任意模块、接口或配置都已按该频率完成实机验证
- BMP280 标称 20 Hz 是推荐工作点。当前 forced 温度 ×2、压力 ×16 转换至少 45 ms，缺少严格 50 ms 周期；理想节奏约 21.3 Hz，未经实测确认。这里没有给驱动新增统一 20 Hz 上限
- JY901B 默认模块输出 200 Hz，新 `0x56` 气压帧去重不能证明每帧都有一次独立压力转换。在两样本 INS 100 Hz 的 SF6 配置下，气压融合受该 INS 更新节奏上限约束，不等于每秒融合 200 次。JY901S 无气压

### BMI088 400 Hz 仍保留可选

以下细节来自 `79eeada` 归档的静态核查，不是最新 400 Hz 最终构建或目标板性能结果：

- SPI 同步配置：加速度计 ODR 400 Hz、带宽 145 Hz；陀螺仪 ODR 400 Hz、带宽 47 Hz
- 需要对应同步与 DRDY 数据就绪中断线路；当前路径没有 FIFO 回补
- 该归档的 I²C 同步 DRDY 配置不完整，不据此声称 I²C 同步路径已可用
- 400 Hz 两样本聚合对应 INS 200 Hz。条件预算下，RET 日志 55592 B/s、RF 日志 67492 B/s；普通队列平均覆盖时间约为 38.6 ms、86.6 ms
- 平均覆盖时间不能替代突发相位、START 过程、介质停顿和任务调度下的最坏缓冲证明；日志预算也不能替代实卡吞吐或 MCU WCET

没有这组 400 Hz 配置的最终构建和 CPU 板测结论。保留可选项供评估，发布推荐仍从已列出的组合起步；不因此修改驱动或增加禁选项。

## 日志损失与验证范围

RF 轻量 `56/16` 的既有 Host 审查采用 IMU 200 Hz、惯性增量 100 Hz、气压 20 Hz、GNSS 25 Hz，`SF6_STATE` 10 Hz、`MEASUREMENT` 120 Hz。无额外延迟时，normal/est 高水位为 13/56 和 6/16，未丢记录。

注入一次 START `f_sync` 80 ms 延迟时，高水位为 41/56 和 16/16，1 次普通 `SF6_STATE`（id 43）入队失败，10 ms 后重试。文件留下 `gap=1`、`overflow=1`、`health=256` 的可检测证据，严格零丢失测试仍为 **FAIL**。

关键 START 的 58 条记录（含 40 条 descriptor）完整，且 sync 成功后才产生内部持久化 ACK；sync 故障时 ACK 为 0。轻量、最简允许少量可检测的普通日志损失，关键记录损失或虚假持久化 ACK 不可接受。这组 Host 结果不证明真实 TF 卡最坏延迟或 MCU WCET，也不覆盖 400 Hz 配置。

旧 `28b168f` 镜像的室内 `mission000041` 实物文件已核验：10188 条完整记录，CRC、序号、尾部与 8 个快照正确；1405 次 Estimator 更新、703 次气压更新，overflow 为 0，最后一次更新距 Landing 6.525 ms。该记录无 GNSS fix、无执行器，仍归属于旧镜像。后续健康 namespace 与故障输出修复已有静态和 Host 检查；最新工程最后一轮插卡台架尚待完成。
