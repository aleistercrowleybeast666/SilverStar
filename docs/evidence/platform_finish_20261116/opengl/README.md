## Product changes

- Both applications wrap their actual Qt static message-box calls with a temporary observer, removed in `finally`; the reused nonblocking transfer notice has a dialog-local observer. Normal operation has no application event filter. On Show it centers the native frame on the immediate parent window and clamps to that screen's logical available geometry; one receiver-bound zero-delay correction follows layout/frame settlement. The original Qt method, default buttons, return values, exceptions and close/save/worker transactions are preserved. GSHC has no idle exit confirmation; none is invented.
- FLP defers the hidden horizontal-trajectory Matplotlib canvas until first display or explicit canvas/figure access. Latest hidden data, language and theme are retained; the same scientific geometry/drawing code is used. Algorithm registry, trusted plugin discovery, numerical runtime, and exact decoder validation still run normally. No rendering exception is swallowed.
- Native GL remains the existing renderer. No software fallback, context-sharing flag, resize loop, driver update or `QOpenGLWindow` rewrite is introduced without evidence of cause.
