# FLP 基线对照 · 2026-11-03

原始全套首个失败位于静止 KF6 回放。用同一 Python 3.14 / Qt 6.10.1 环境，在 Git `8a25f99e` 的隔离 FLP 源码和本轮 `8d0302a4` 上分别执行七个实际失败样本。导出仅含 FLP 源码/测试、所需共享数据契约及版本工具；早期基线准备缺少工具模块，退出 4，原始日志保留。补齐相同提交的依赖后，七个用例在两端都按相同原因失败。

* 静止 KF6 与比较曲线两个用例都未提供算法 revision，KF6 的 `ProcessModelRevision_Resolve` 报 `kf6_algorithm_revision_missing`。本轮未改 KF6 实现或这两个测试。
* 两个气压计诊断用例使用缺少 `devices` 的 SimpleNamespace。云任务取消模拟使用缺少 `metadata` 的 object。相同错误也发生在基线。
* 两个缓存/审计用例在两个版本的较长临时路径下都发生 Windows `WinError 3`，出现在临时文件更名为较长内容哈希文件名时。保留所有原断言，只缩短测试临时路径，两端各自 2 项全部通过。该对照验证路径长度对这两个样本的影响，没有验证所有 Windows 文件系统配置。

七个样本的测试文件在两提交之间的 Git blob 均相同。全套其他失败需要依据各自日志判断；这里的对照仅覆盖实际执行的七个样本。[逐项来源与结论](comparison.json) · [实际命令与完整日志](comparison-logs.zip)
