# Android GSHC workspace rules

- Work in this owning monorepo application. Cross-component integration requires explicit task scope; preserve other application owners and user changes.
- Read protocol references from frozen `v0.1.2`, commit `c31c13cc0686a56a3184d4f207fd3816c5d39696`. Do not silently substitute the dirty development checkout.
- For file service and export, the user-authorized shared v1 contracts at `cb944b7c5a844da2f277494662801f2179a268ad` supersede this project's original drafts. Use `reference/shared-0.1.3/contracts/` and its SOURCE.json; do not independently change wire or manifest schemas. SSLOG remains 0.0; decoder packages remain 1.2. Unknown device/boot identities cannot authorize resume by token alone.
- Current LOGFILE policy at `f2ce541382589cb606e1f5b21f6fd982357eaa54` additionally disables device deletion and cross-connection resume. Keep its independent `reference/integration-f2ce541` snapshot; every attempt must use a new file and start at offset 0, preserving previous files.
- Default simulation/read-only. No hardware connection or application TX, no auto ACK/UNLOCK/START/parachute. A source-level USB gate is not hardware validation.
- Preserve original session bytes, recorded times and actual protocol identities. Do not claim AIR JSONL is a native TF log or directly FLP-compatible.
- Copy/cut must preserve sources on export/readback failure. Never delete after a share intent. Cut requires closed recording, complete target readback, and separate explicit user confirmation. Initial implementation uses a clearly disclosed recoverable recycle directory; permanent purge is not implemented or authorized by this file.
- Keep minimal evidence: one current verification report, compact fixtures and necessary source provenance. Use a caller-selected BuildRoot for generated classes and test scratch (normal local default `build/`); Gradle cache under an explicitly chosen D-drive location. Do not copy entire repositories, create repeated large logs, or retain downloaded installers unnecessarily.
- Cache cleanup is limited to verified generated files created by this task. Confirm resolved paths stay under this project before recursive removal. Preserve raw user data, decoder packages, fixtures, source snapshots and formal evidence. These rules do not authorize any new user-file, device-TF, or repository deletion.
- Keep APK build, preview rendering, emulator testing and real-device validation separate in reports. No push, tag, release, Android Studio installation, SDK license acceptance or large SDK download without the relevant user authorization.
