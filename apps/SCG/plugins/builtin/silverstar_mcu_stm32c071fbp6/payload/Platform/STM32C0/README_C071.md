STM32C071FBP6 retains historical project identity. Current UART Ground generation
additionally supports the exact builtin SSGS1.0 software-candidate board profile
(TSSOP20 GP, HSI48, USART2 DMA and SPI1); it does not admit arbitrary historical
C071 imports or Flight generation. Native MCU USB CDC remains unavailable.

The board and selected HAL/CMSIS payload are software candidates, not verified
user-PCB wiring. See the SCG SSFC1.0/SSGS1.0 example guide and the owning board's
hardware-provenance.json for fixed resources, assumptions and source hashes.
