# SCG — System Configuration & Generation

The application lives in this directory. Run `python SCG.py` from the repository
root, or `python apps/SCG/SCG.py`. The legacy `apps/FCCG/FCCG.py` launcher and
`silverstar-fccg` entry point remain supported.

Python package names (`silverstar_fccg`), declarative plugin identities and
existing project formats are unchanged. Plugins remain in `plugins/builtin`
and `plugins/installed` beside this application's source.

See the [application documentation](../../docs/FCCG/APP_README.md),
[architecture](../../docs/FCCG/ARCHITECTURE.md) and
[workspace guidance](../../AGENTS.md). Historical documentation and evidence
retain the `docs/FCCG` namespace; existing private `.work` directories retain
their original locations.
